# Controllers

This section of the project contains all the controllers of the application

## Available Controllers

-   **Auth Controllers**

exports all controllers required for authentication
   
    => sign in 

    => sign up

    => sign out

    => verify otp

    => refresh token

-   **Users Controllers**

exports all controllers required to manage users 
    
    => get all users

    => get details about a single user

    => update a user

    => delete a user

    => get user statistics 


-   **Books Controllers**

exports all controllers required to manage users
    
    => create a book

    => get all books

    => get a single book

    => update a book

    => delete a book

    => get books statistics


-   **Borrow Controllers**

exports all controllers required to manage users

    => borrow a book

    => get all borrowed books

    => get user borrowed books

    => get books borrowed by a user

    => extend return date of borrowed book

    => update status of a borrowed book

    => cancel request for borrowed book

    => delete book from borrowed books

    => get statistics for all borrowed books


-   **Review Controllers**

exports all controllers required to manage review

    => review a book

    => get reviews for a book

    => update a review
    
    => delete review

    => get statistics for all reviews
